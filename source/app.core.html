    app.core.config.get_auth_backend() → str[source]¶

    Determine the auth backend from FLUX_AUTH_BACKEND.

    FLUX_REQUIRE_AUTH predates FLUX_AUTH_BACKEND: it meant database users plus the shared-secret token handshake, so it maps to “shared-secret”.
